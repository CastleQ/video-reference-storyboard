# 레퍼런스 영상 → 스토리보드

유튜브 레퍼런스 영상 몇 개를 넣으면 **컷 분석 → 패턴 비교표 → 새 스토리보드**까지 만들어 주는 작업 공간입니다.
클로드 코드 **클라우드 세션**에서 이 리포를 열면 영상 분석 도구(watch)가 자동으로 준비됩니다.

## 쓰는 법

1. `projects/_template` 폴더를 복사해 `projects/2026-11_프로젝트명`으로 이름을 바꿉니다. (클로드에게 "새 프로젝트 만들어줘"라고 해도 됩니다)
2. `brief.md`에 만들 영상을, `links.md`에 레퍼런스 링크를 적습니다.
3. 클라우드 세션에서 이렇게 말합니다.
   > `projects/2026-11_프로젝트명` 진행해줘. 1단계부터.
4. 단계마다 결과가 리포에 저장됩니다. 검토는 GitHub에서 `storyboard.md`를 열면 썸네일과 함께 표로 보이고, 편집은 `storyboard.xlsx`를 내려받아 하면 됩니다.

## 결과물

| 파일 | 내용 |
|---|---|
| `analysis/NN_제목.md` | 영상별 컷 분석 (캡처 포함) |
| `patterns.md` | 영상끼리 비교한 공통 패턴·차별 포인트 |
| `storyboard.md` | 새 영상 스토리보드 (GitHub에서 바로 보기) |
| `storyboard.xlsx` | 같은 스토리보드, 편집용 엑셀 |

## 유튜브가 막힐 때

클라우드 서버에서는 유튜브가 "로봇 확인"으로 다운로드를 막는 경우가 있습니다. 그럴 땐:
- 해당 영상을 내려받아 GitHub 웹에서 `inbox/` 폴더에 업로드합니다. (웹 업로드는 파일당 25MB까지)
- 클로드에게 "inbox 영상으로 분석해줘"라고 하면 분석 후 영상 파일은 지웁니다.
