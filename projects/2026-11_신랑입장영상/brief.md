# 내가 만들 영상

- **제품·주제:** 결혼식 신랑 입장 영상. 야구가 취미인 신랑이 야구장 마운드에서 걸어 나와 경기장 안쪽 복도를 지나, 무거운 문을 열고 빛 속으로 입장한다.
- **목표 길이:** 본편 **33초** (30~33초에 문 열림) + 문이 열린 뒤 **대기 화면 20초 루프**
- **올릴 플랫폼:** 예식장 스크린 (반으로 열리는 문 + 스크린에 투사). **16:9, mp4**
- **보는 사람(타깃):** 예식 하객
- **영상이 끝났을 때 시청자가 할 행동:** 문이 열리고 실제 신랑이 등장하는 순간에 환호·박수
- **꼭 들어가야 할 것:**
  - 톤: 레퍼런스 01처럼 절제된 고급 (차분한 네이비·보라 계열, 과한 그래픽 없음)
  - 신랑 얼굴은 **끝까지 숨김** (뒷모습·발·손 디테일만) → 문이 열릴 때 실물로 처음 공개
  - 멈춤 장치(카운트다운·타이틀) 없이 **문틈으로 새하얀 빛 → 화이트 디졸브**로 30초쯤 문 열림 신호
  - 흐름: 관중 가득한 야구장 마운드를 걷는 뒷모습(핸드헬드 팔로잉) → 선수들 환호에 여유 있는 주먹 인사 → 경기장 건물 안으로(컷 전환: 발 클로즈업, 측면 고정 카메라에서 프레임 인/아웃 등) → 복도 끝 두껍고 무거운 문 앞에 섬 → 옷매무새 클로즈업 → 문을 열며 빛 → 화이트 디졸브
  - 대기 화면: **D. 홈런 세리머니** — 밤 경기장 위로 불꽃과 종이 가루. 금색·흰색 위주로 절제, **정중앙(문 이음새)은 비워 둠**
- **피하고 싶은 것:** 02의 네온·만화풍 그래픽, 영어 가사 타이포 / 03처럼 장면을 너무 많이 바꾸는 것 / 화면 정중앙에 글자·얼굴 두기
- **제작 여건:** 모든 소스는 **생성형 AI**로 제작. 편집(음원 싱크 등)은 작업자가 진행
- **음악(참고용):** 이원석 「큐사인」 (사회자 멘트 + 입장 시작 ver.) — 0:29.5 끊김 → 0:30 터짐

## 예식장 사양
- **확정:** 스크린 16:9 / 문 이음새 = 화면 정중앙 / **파일 하나로 전달**
- **파일 구성:** 본편 33초 + 대기 화면(W2 20초)을 **여러 번 이어 붙인 긴 파일 하나** (예식장에서 파일 전체를 반복하면 0초로 돌아가므로)
- **확인 필요:**
  - 문이 열린 뒤 대기 화면이 몇 분 떠 있어야 하는지 (→ 반복 횟수 결정, 여유 있게)
  - 문 뒤 하얀 역광 조명 가능 여부 (화이트 디졸브와 연결)
  - 파일 형식·코덱·용량 제한
  - 리허설 상영 가능 여부
